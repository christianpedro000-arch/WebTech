My First CSS Page

CSS (Cascading Style Sheets) is a programming language used to design and style web pages. Its main purpose is to make websites look attractive, organized, and visually appealing. CSS controls the appearance of HTML elements, such as text colors, font styles, backgrounds, borders, spacing, and layouts. Without CSS, websites would look plain and simple because they would only display basic content without much design or decoration.

Another important purpose of CSS is to make websites more user-friendly and responsive. It allows web developers to create layouts that adjust to different screen sizes, such as computers, tablets, and mobile phones. CSS also helps maintain a consistent design across multiple web pages, making websites easier to navigate and more enjoyable to use. Overall, CSS improves the appearance, accessibility, and user experience of a website.

Reflection

The difference between inline, internal, and external in CSS is that the Inline CSS is placed directly in the HTML element using style attribute. The Internal CSS is placed inside a style element in the HTML document's head section. And the External HTML is placed in a separate .css file and is linked to the HTML document.

The method I would use for a website with multiple pages would be External CSS. Because to me having a separate .css file makes it easier for me to find the element im finding.
