HTML Text Formatting

Formatting Tags

<b> Bold Text uses for visual emphasis only.
<strong> Strong text marks content of great importance.
<i> Italic text uses for an alternate voice.
<em> Emphasized text shows stressed emphasis.
<u> Underlined text used to underline texts.
<mark> Marked text is highlighted for reference.
<small> Small text is used for shrinking text and fine print.
<del> Deleted text shows removed content.
<ins> Inserted text shows newly added content.
<sub> Subscript example: H20
<sup> Superscript example: X2

HTML stands for HyperText Markup Language.
