+    <h1>My First CSS Page</h1>
+    <p style="background-color: white; font-family: Arial, Helvetica, sans-serif; font-size: 16px; padding: 20px;">
+        CSS (Cascading Style Sheets) is a programming language used to design 
+        and style web pages. Its main purpose is to make websites look attractive, 
+        organized, and visually appealing. CSS controls the appearance of HTML elements, 
+        such as text colors, font styles, backgrounds, borders, spacing, and layouts. 
+        Without CSS, websites would look plain and simple because they would only display 
+        basic content without much design or decoration.
+    </p>
+    <p>
+        Another important purpose of CSS is to make websites more user-friendly and responsive. 
+        It allows web developers to create layouts that adjust to different screen sizes, such 
+        as computers, tablets, and mobile phones. CSS also helps maintain a consistent design 
+        across multiple web pages, making websites easier to navigate and more enjoyable to use. 
+        Overall, CSS improves the appearance, accessibility, and user experience of a website.
+    </p>
